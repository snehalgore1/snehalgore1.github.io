# Project thumbnails

Save each image in this folder using the exact file name listed (for example `mini-tensorrt.png`).
The site picks it up automatically; any project without an image keeps its current look.
`.png`, `.jpg` and `.webp` all work.

## Specs
- **16:9, 1600×900 px**, under ~400 KB (squoosh.app compresses well).
- No text, letters, numbers, logos or brand marks in the image. The site draws the title on top.
- For the 4 case studies and 4 featured projects, the bottom half sits under the title, so keep it calm and simple.

## Shared style (paste this first, then the project prompt)

> Flat editorial illustration with soft isometric depth, clean vector shapes, subtle grain texture.
> Warm palette only: butter yellow #F4C542, cream #FFF8D9, ivory #FFFDF7, deep espresso brown #2C2521,
> cocoa #6B4E3D, muted sage green #78835A, small gold accents #C89B19. Soft studio lighting, gentle shadows.
> Main subject in the upper half, calm uncluttered lower half. No text, no letters, no numbers, no logos,
> no people's faces. 16:9, 1600×900.
